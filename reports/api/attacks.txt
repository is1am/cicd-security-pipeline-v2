Эскалация привилегий и IDOR

Пользователь ivanov пытается назначить себе роль ADMIN
PUT /api/v1/admin/users/4/role    [токен пользователя ivanov]
  тело запроса: {"role": "ADMIN"}
  ответ: 403 Forbidden
  {"detail": "Недостаточно прав для выполнения операции"}

Пользователь ivanov подставляет в адрес чужой id (профиль администратора)
GET /api/v1/users/1    [токен пользователя ivanov]
  ответ: 403 Forbidden
  {"detail": "Недостаточно прав для выполнения операции"}

Свой профиль пользователю доступен
GET /api/v1/users/4    [токен пользователя ivanov]
  ответ: 200 OK
  {"id": 4, "username": "ivanov", "roles": ["USER"]}
